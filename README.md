# Target Brazil E-Commerce Business Performance Case Study

## Overview

This project presents a comprehensive SQL-based business performance analysis of the Target Brazil E-Commerce dataset using Google BigQuery. The objective is to analyze customer purchasing behavior, sales performance, logistics, freight costs, and payment trends through SQL queries and derive meaningful business insights.

- Google BigQuery

## Dataset

The Target Brazil E-Commerce dataset contains information related to:

- Customers

- Sellers
- Payments
- Reviews

## Key Insights

- Order volume increased over time.
- Revenue varied across Brazilian states.
- Credit Card was the most preferred payment method.
- Freight costs differed significantly by region.
- Delivery efficiency varied across states.
